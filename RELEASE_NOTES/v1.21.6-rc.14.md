MacCrab v1.21.6-rc.14

This candidate supersedes the unpublished rc.13 after its installed-host audit
found two release-blocking upgrade and containment defects.

- A retained schema-v8 event store now receives the smallest bounded transition
  reserve that covers both legacy evidence and exact whole-family headroom.
  This fixes a one-MiB rounding gap that made the system extension stop before
  ingestion and repeatedly restart on an upgraded host.
- The sandboxed plugin lane canonicalizes its scratch directory once and uses
  that same `/private/var/...` path in the sandbox profile, broker policy and
  child request. Both C and Swift containment probes can therefore prove their
  allowed fd-3 broker read while every undeclared surface remains denied.
- Targeted regressions cover the exact retained-host footprint, bounded reserve
  selection, pinned WAL behavior and path canonicalization.
- The live source containment corpus exercises the reference plugin plus C and
  Swift adversarial probes under the deny-default macOS sandbox.

All rc.13 evidence-integrity, bounded-memory, storage-recovery, read-only tooling,
credential-sanitization and release-qualification changes remain included.

Minimum macOS 13.0. This release candidate must pass clean CI, signing,
notarization, exact-candidate containment and the uninterrupted installed-host
qualification before publication.
