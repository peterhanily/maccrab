MacCrab v1.21.5

A correctness and honesty release. This build makes several surfaces report what the engine actually knows — no placeholders presented as findings — tightens the fleet telemetry prototype, and closes a detection-profile gap.

Detection
- Sequence and graph rules now honor the rule profile like single-event rules do. Under the default "stable" profile, curated stable-tier rules run and experimental ones stay disabled (set rule_profile: "all" to run everything). Deprecated rules never run under any profile.
- Promoted six multi-step kill-chain sequence rules (ransomware, worm self-propagation, supply-chain and typosquat full chains, credential-read-after-require, token-revocation polling) to the stable tier so they remain enabled by default.

Onboarding
- The first-run setup checklist now verifies Full Disk Access and System Extension approval live, instead of assuming them, and only reports the Mac as protected once those checks pass.
- New installs can choose a workspace density (Basic / Standard / Advanced) during setup; Basic is the default for new users.
- Clearer, accurate wording for the optional response modules (previously labeled "Active Prevention").

Intelligence & forensics
- Package Freshness now shows "Not scanned" and "—" until a real registry scan has run, rather than defaulting to "up to date" with zero staleness.
- The get_intent_posterior MCP tool now returns the engine's real recorded posteriors instead of an always-empty local result.
- Exported evidence bundles ship a real outer-archive SHA-256 sidecar (`<archive>.sha256`) for transport-integrity checks.

Fleet telemetry (self-hosted prototype)
- Fleet telemetry is now strictly outbound-only: nothing returned by a fleet server is consumed by endpoints.
- The client requires HTTPS (plain HTTP is accepted only for loopback); the reference server defaults to a loopback bind and authenticates its dashboard endpoint. Fleet remains off by default and is documented as a prototype, not a production feature.

Under the hood
- Cleared all Swift 6 language-mode concurrency warnings.
- Added a burst-load benchmark and written rule-promotion criteria for contributors.

Minimum macOS 13.0. Notarized and stapled; updates via Sparkle.
