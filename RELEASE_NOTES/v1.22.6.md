# MacCrab v1.22.6

## Detection and engine reliability

- **File floods no longer push out process events.** Agent file reads now ride
  the file lane, and most signal events, which no rule reads, are dropped at
  the sensor.
- **Sequence rules now shed history from the rule holding the most,** after
  merging a process's repeated entries. A chain whose middle step arrives late
  can now complete.
- **Signature-based exemptions now check the running code,** and developer-tool
  folders no longer lower alert severity.
- **Startup no longer stops** on a full TraceGraph store or a slow database
  upgrade check.

## Storage and performance

- **Repeated runs of one unsigned binary no longer fill TraceGraph,** and a
  full store drains instead of staying paused for hours.
- **Detection no longer waits on TraceGraph.**
- **Opening Settings no longer changes engine storage policy.**

## Rule management and explainers

- **Re-enabling a rule now takes effect without a restart** and no longer
  deletes a custom rule or its tuning.
- **`maccrabctl why` explains sequence, graph and dashboard rules.** MCP
  `explain_alert` finds any stored alert and points to `maccrabctl why`.

## Fixes

- Allowlist entries scoped to a file hash or this host now apply; review them
  with `maccrabctl allow list`.
- Command-line passwords are redacted by default.
- Notifications follow your minimum severity.
- The plugin store no longer says MacCrab's own plugins are sandboxed.
- Rule reloads no longer fail with many custom rules.

## Known limitations

Sustained extreme bursts, such as large package installs during other heavy
work, can still drop file events. Drops are counted in health telemetry; see
[KNOWN_LIMITS.md](https://github.com/peterhanily/maccrab/blob/main/KNOWN_LIMITS.md).

## Upgrade notes

Installs older than v1.22.0 receive this update as critical. Upgrading from
v1.21.5 or earlier changes the event database format; see the
[rollback runbook](https://github.com/peterhanily/maccrab/blob/main/docs/ROLLBACK_RUNBOOK.md).

Minimum macOS 13.0.
