# MacCrab v1.22.6

## Detection and engine reliability

- **SMAppService login-item persistence and the critical Full Kill Chain campaign are now detected,** and programs that launchd starts, LaunchAgent payloads included, now reach the rules.
- **Agent file-read and signal floods no longer push out process events.**
- **One noisy sequence rule no longer pushes out the others' history,** and a chain whose middle step arrives late can now complete.
- **Signature-based exemptions now check the running code,** and developer-tool folders no longer lower alert severity.
- **Startup no longer stops** on a full TraceGraph store or a slow database upgrade check.

## Storage and performance

- **Repeated runs of one unsigned binary no longer fill TraceGraph,** and a full store no longer stays paused for hours.
- **Detection no longer waits on TraceGraph.**
- **Opening Settings no longer changes engine storage policy.**

## Rule management and explainers

- **Re-enabling a rule now takes effect without a restart** and no longer deletes a custom rule or its tuning.
- **`maccrabctl why` explains sequence, graph and dashboard rules,** and MCP `explain_alert` finds any stored alert.

## Fixes

- Allowlist entries scoped to a file hash or this host now apply; review them with `maccrabctl allow list`.
- Command-line passwords are redacted by default.
- Notifications follow your minimum severity.
- The plugin store no longer says MacCrab's own plugins are sandboxed.
- Rule reloads no longer fail with many custom rules.
- The DMG's `install.sh` now restarts a running MacCrab, so the new version takes effect.

## Known limitations

Sustained extreme bursts, such as large package installs during other heavy work, can still drop file events, which health telemetry counts; see [KNOWN_LIMITS.md](https://github.com/peterhanily/maccrab/blob/main/KNOWN_LIMITS.md).

## Upgrade notes

Scheduled update checks offer this release over about a week; Check for Updates… in the menu-bar menu offers it at once (open the dashboard first). Installs older than v1.22.0 receive this update as critical. Upgrading from v1.21.5 or earlier changes the event database format; see the [rollback runbook](https://github.com/peterhanily/maccrab/blob/main/docs/ROLLBACK_RUNBOOK.md).
