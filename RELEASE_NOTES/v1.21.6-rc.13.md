MacCrab v1.21.6-rc.13

This candidate focuses on preserving exact recent security evidence while
keeping disk, memory and background work bounded under sustained event load.

- Recent events are written to an authenticated journal; dashboard and search
  data are explicitly treated as a bounded projection of that source.
- Search, event-rate and histogram views now warn when retention or projection
  coverage is incomplete. Missing history is no longer displayed as zero.
- Deferred hashes, signing details, reviewed matches and other late enrichment
  are durably attached to the original event before reviewed alerts fan out.
- Oversized or malformed records become visible evidence gaps with stable
  identities instead of silently truncated or apparently complete events.
- The schema-v8 upgrade preserves legacy rows, inherited truncation and corrupt
  records through authenticated migration and quarantine ledgers.
- Journal expiry rolls exact retained events into historical aggregates before
  removing complete blocks, with typed gaps retained for incomplete evidence.
- Raw events, enrichment work, journal preparation and storage compression now
  share a process-wide memory envelope with byte-aware backpressure.
- SQLite writes recheck real family headroom under the writer lock, and a
  finalized store can reopen in shed-only mode under disk pressure so recovery
  remains available.
- CLI and MCP reads use read-only store connections and exact snapshots where
  the command promises exact evidence.
- Credential sanitization now catches split and compact command-line secrets
  while preserving useful IP, hostname, path and hash evidence.
- The heartbeat and release gate now prove terminal persistence, event-window
  coverage, rule-corpus identity and journal migration conservation against the
  exact signed candidate.

Minimum macOS 13.0. This release candidate must still pass signing,
notarization, containment and the uninterrupted installed-host qualification
before publication.
