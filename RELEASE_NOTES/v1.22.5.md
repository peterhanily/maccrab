# MacCrab v1.22.5

This patch restores the Homebrew install on current Homebrew, lets the
"Protection degraded" state clear on its own once a write failure has passed,
and makes the diagnostics export explain that state.

## Install

- **`brew install --cask peterhanily/maccrab/maccrab` works again on
  Homebrew 7.** Homebrew deprecated the Ruby `postflight` block in favour of
  structured `postflight_steps`, and the deprecation is an error on any Mac
  where `HOMEBREW_DEVELOPER` is set, so new installs stopped with "Calling
  `postflight` is deprecated". The cask's post-install work is now declared as
  install steps. The published tap was updated ahead of this release; this
  release keeps the next cask bump from regressing it.

## Protection status

- **A write failure earlier in the engine's life no longer keeps protection
  degraded.** The TraceGraph writer's failed-batch totals and the alert write
  failure count both held the Overview, sidebar and menu bar at "Protection
  degraded" until the engine was restarted, however long ago the failure
  happened and although writes had recovered. The engine now reports whether a
  failure happened inside the last 15 minutes, and only a current failure
  degrades protection. System Health keeps showing the trailing 24-hour alert
  write failure count as history.
- **The diagnostics export explains the protection verdict.** A new
  `protection` block (export schema 4) lists the verdict, the reasons behind
  it, and every input the app checks, so a "Protection degraded" report can be
  diagnosed from the file. Free-text engine details stay out of the export.

## Release tooling

- **The pre-push gate tests the tree being pushed.** A push from a linked
  worktree previously ran CI against the main checkout's tree.

## Upgrade notes

Upgrading from v1.21.5 or earlier still changes the event database format.
Reinstalling an older app over a migrated database is not a supported rollback;
see the
[rollback runbook](https://github.com/peterhanily/maccrab/blob/main/docs/ROLLBACK_RUNBOOK.md).

Minimum macOS 13.0.
