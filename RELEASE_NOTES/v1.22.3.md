# MacCrab v1.22.3

This patch adds the Rave forensic plugin views merged since v1.22.2, removes
two remaining sources of false DGA alerts, and hardens the release process
against the failure modes that delayed v1.22.2.

## Rave forensic plugins

- **Plugin results open in dedicated views inside the scan detail.** Secret
  Trail lists where copies of each credential type appear, by file and line,
  without showing the secret itself. Repo Tripwire and Script Trace list their
  static findings with the trigger and the review each one calls for; the
  remaining plugins share one findings view. Every view can be filtered and
  copies a hand-off note per finding, with coverage gaps shown beside results.
- **You choose what each file-reading plugin may scan.** The plugin detail
  panel has a "Selected sources" picker; Run stays disabled until a selection
  is saved. Up to 32 files or folders inside your home folder can be selected,
  symbolic links are refused, and selections are stored with private
  permissions.
- **Scan evidence can become a review kept inside the encrypted case.**
  "Review evidence" gathers a scan's findings, coverage and gaps into a review
  stored in the same encrypted case, where decisions can be recorded, compared
  against earlier reports, and rechecked with current rules. Reviews collect no
  new evidence, and a plaintext case cannot save one.
- Plugin detail panels describe network access as declared by the plugin's
  manifest.
- **A catalog "Run on this Mac" verifies the installed plugin before it
  starts.** Case encryption and run disclosures are chosen from the installed
  plugin's signed manifest, so a plugin whose listing requires an encrypted
  scan can no longer write to a plaintext case; a missing or unverifiable
  manifest stops the run with a visible reason.
- **Companion tools for Decoy, Exit Check and Build Witness** are attached to
  this release as signed universal binaries
  (`decoy-tools`, `exit-check-tools`, `build-witness-tools`, each 0.1.0).
  Their SHA-256 checksums are listed on the release page.

## Fewer false alarms

- **DGA detection no longer flags reserved or abbreviated service names.**
  Names under special-use TLDs (`.invalid`, `.test`, `.example`, `.localhost`,
  `.local`, `.arpa`) can never be registered, so connectivity probes no longer
  raise a HIGH alert. Hyphenated service names such as `gsp64-ssl.ls.apple.com`
  and GitHub's `glb-<hex>` hosts are no longer read as generated text, while
  vowel-free generated names are still flagged.

## Reliability

- **A non-interactive `install.sh` run exits 0 after a successful install.**
  Without a terminal, the closing "Open MacCrab.app now?" prompt previously
  made the script exit 1. The prompt is offered only on a terminal.

## Release process

- The site's Sparkle appcast and `release.json` are published in one commit,
  so the website can no longer advertise a stale build after a release.
- The release pipeline can resume a publication whose tag was pushed but whose
  branch push failed, checks the remote before spending CI time, verifies its
  inputs before the installed-host capture, reuses a passing clean-CI receipt
  instead of running the full suite a third time, and checks free disk space
  before building.

## Upgrade notes

Upgrading from v1.21.5 or earlier still changes the event database format.
Reinstalling an older app over a migrated database is not a supported rollback;
see the
[rollback runbook](https://github.com/peterhanily/maccrab/blob/main/docs/ROLLBACK_RUNBOOK.md).

Minimum macOS 13.0.
