# MacCrab v1.22.4

This patch removes a per-event cost in the detection engine that made it
consume most of a CPU core, and drop priority events, whenever an AI coding
agent or build tool wrote files at a high rate.

## Engine performance

- **Home-directory validation is no longer repeated for every file event.**
  Quarantine and AI-tool enrichment resolve the owning user's home for each
  file event. Each answer re-listed `/Users`, re-walked the home directory
  descriptor by descriptor and repeated the account lookups, which came to
  about seven directory walks per event. During an agent file storm the engine
  issued roughly 68,000 file system calls per second, ran at 100–150% CPU, and
  shed priority-lane events. The validated answer is now reused for five
  seconds. Per-file ownership checks are not cached, so a path component
  replaced by a symbolic link inside that window still fails closed.

## Upgrade notes

Upgrading from v1.21.5 or earlier still changes the event database format.
Reinstalling an older app over a migrated database is not a supported rollback;
see the
[rollback runbook](https://github.com/peterhanily/maccrab/blob/main/docs/ROLLBACK_RUNBOOK.md).

Minimum macOS 13.0.
